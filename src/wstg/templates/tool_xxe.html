Tools › XML injection / XXE

WSTG-INPV-07 step 2. Finds the XML entry points from katana-crawl and har-browse — XML request bodies (application/xml, text/xml, soap+xml), parameters whose value is inline XML, and parameters that reference an XML resource (value like x.xml, or a name like xmlPreview). For each it sends two standard payloads reusing the captured session: a structure break (stray ]]>, an unmatched tag and a bare entity — looks for a new XML parser error), and an in-band XXE probe (a DOCTYPE with an external entity to a unique, non-existent local path — looks for that path echoed back, i.e. the parser tried to resolve it). No real file is read. Out-of-band XXE (an http:// entity) and uploaded docx/svg/SAML stay manual. It sends active payloads, so a WAF may flag it — run it by agreement.
