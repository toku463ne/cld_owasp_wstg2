WSTG-BUSL-02 step 2. Takes real requests from the capture (har-browse), adds or overrides parameters the UI never offers (price, role, status, userId, discount), and compares each response with its baseline. It reuses the captured session and contacts only this host. The point is to collect the evidence across many requests at once; the judge (step 3) decides later whether the server trusted a value it should own. It changes the target, so run it by agreement.
