WSTG-BUSL-02 step 2. Takes a real request from the capture (har-browse), adds or overrides parameters the UI never offers (price, role, status, userId, discount), and compares the response with the baseline. It reuses the request's captured session and contacts only this host. It changes the target, so run it by agreement. The verdict is the judge's (step 3): a changed result or an echoed value may mean the server trusted a client value it should own.
